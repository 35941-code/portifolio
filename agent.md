# Regras do projeto

- Site de portfólio pessoal em HTML, CSS e JavaScript puro (sem frameworks, sem bibliotecas de animação).
- Antes de criar ou alterar qualquer coisa, leia referencias.md, identidade.md e funcionalidades.md.
- Estrutura de arquivos: index.html, style.css, script.js e a pasta img/ (imagens e logo). O HTML tem seções nomeadas: início, sobre, habilidades, projetos e contato.
- Estilo geral: **minimalista**. Muito espaço em branco, títulos grandes e leves, linhas finas separando o conteúdo, sem cor de destaque e sem enfeites. Nada de layout genérico de template.
- Use variáveis CSS (:root) para cores, fontes e medidas, para facilitar trocar o visual depois.
- Sempre responsivo (celular, tablet e computador): adapte o layout, não apenas diminua.
- Acessibilidade: HTML semântico, contraste alto, foco visível, navegação por teclado, textos alternativos e suporte a prefers-reduced-motion.
- Não invente projetos, textos ou dados pessoais: use só o que está em identidade.md. Onde faltar dado, deixe `[PREENCHER]`.
- O formulário de contato não tem backend: só valida e avisa que nada foi enviado.
- Depois de cada mudança, explique em 2 linhas o que foi feito.
